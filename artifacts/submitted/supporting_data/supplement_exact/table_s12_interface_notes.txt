PVSE is a support-side module, not a replacement backbone. Plug-in compatibility means that the downstream method exposes the required interface; it is not a universal improvement theorem. Non-compatible cases include black-box classifiers without support access, no spatial feature map or equivalent patch representation, no support-mask interface for PVSE-R-HD, no support-weight interface for PVSE-R-Soft, downstream classifiers that cannot recompute predictions after deletion for PVSE-C-HD, and protocols forbidding query-level prediction override for PVSE-C-Switch.

PVSE-R-HD is the natural plug-in form for TraNFS-style support aggregation. PVSE-R-Soft requires valid sample-weight or attention-mask semantics. The FEAT plug-in uses PVSE-R-HD as support pre-cleaning while the downstream FEAT model remains frozen.
