# Data and checkpoints

The paper implementation uses the following model and dataset interfaces.

## Paper ResNet-12

The trained checkpoint is distributed through the GitHub Release:

```text
backbone_v315_best_for_v316_logreg.pth
size: 49,934,618 bytes
sha256: 763f0ae0a2233f16a9bd551ea22e2997e95dde8efdeb79270e52d9bd87bd1568
```

All applicable paper YAMLs record this digest. Loading is strict and writes `checkpoint_load_report.json`; missing, unexpected, or shape-mismatched keys are fatal. The backbone exposes global `[N,640]` and layer-4 spatial `[N,640,5,5]` outputs.

Main miniImageNet layout:

```text
ROOT/train/train/<class>/<image>
ROOT/val/val/<class>/<image>
ROOT/test/test/<class>/<image>
```

Set `PVSE_MINIIMAGENET_ROOT`, `PVSE_BACKBONE_CHECKPOINT`, `PVSE_OUTPUT_ROOT`, and `PVSE_DEVICE`.

## Table 9 external datasets

Supported identifiers are CUB, Caltech101, DTD, FGVC_Aircraft, OfficeHome, and PACS. Build the local index with `pvse-build-external-index`, then set `PVSE_EXTERNAL_INDEX`. Table 9 reuses the clean verifier generated by Table 4 and performs fixed transfer without external tuning.

## FEAT

Use upstream Sha-Lab/FEAT commit `47bdc7c1672e00b027c67469d0291e7502918950` and checkpoint:

```text
miniimagenet_feat_5shot.pth
size: 56,316,902 bytes
sha256: ee54213c754b2c25d07bb7b032549140d7be8d4e253f597cfa57a314696191ee
```

Set `PVSE_FEAT_CODE_ROOT`, `PVSE_FEAT_CHECKPOINT`, and `PVSE_FEAT_MINIIMAGENET_ROOT`. The adapter loads checkpoint parameters with `strict=True` and uses FEAT's native set-to-set inference.

## Run records

Paper runners emit effective configurations, environment and checkpoint reports, episode/corruption manifests, per-support and per-query outputs, and aggregate summaries in the selected local output directory.
