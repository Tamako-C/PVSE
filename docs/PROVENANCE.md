# Paper-to-code records

`provenance/provenance_manifest.json` maps each reported paper item to its formal configuration, implementation modules, generated outputs, and submitted reference artifacts.

`provenance/paper_experiments.csv` provides a compact table of the reported experiment families and their expected outputs.

`assets/checkpoints.json` records the exact ResNet-12 and FEAT identities used by the paper implementation.

`provenance/real_data_smoke_certificate.json` records the reduced-count real-data integration verification across the reported experiment families.
