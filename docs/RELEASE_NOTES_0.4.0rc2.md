# PVSE v0.4.0rc2

Accepted-version release candidate for PVSE.

This release provides:

- the complete runnable source code and formal configurations for the experiments reported in the accepted paper;
- the submitted supporting artifacts and their verification utilities;
- the trained ResNet-12 backbone checkpoint through the GitHub Release;
- documented local-path interfaces for miniImageNet, the external transfer datasets, and FEAT;
- the installable `pvse-fsl` Python package.
